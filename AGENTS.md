# AGENTS.md

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues (MagiqueDeveloper/DepotTools), managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to identically-named labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Releases

Release: Before changing branches, versions, updater behavior, GitHub Actions, or GitHub releases, read `docs/releases.md`.
